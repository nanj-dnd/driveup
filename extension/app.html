One-time setup

Driveup needs its own Google sign-in before anyone can use it. You do this once. Everyone you share the extension with skips it.

  1. Open Google Cloud and create a project (any name).
  2. Turn on the Google Drive API for it.
  3. Under Google Auth Platform, set up the app: name it Driveup, choose External, and add your email.
  4. Under Clients, create an OAuth client. Pick Web application and add this as an authorized redirect URI:
  5. Under Audience, press Publish app so anyone can sign in (Driveup only asks for access to files it uploads, so Google doesn't need to review it).
  6. Paste the client ID into config.js in the extension folder, then reload the extension at chrome://extensions.

Driveup is already open in another tab.

Uploads run from that tab, so you don't get the same file uploaded twice.

Upload big files to Google Drive without watching over them.

  • Close the lid, lose wifi, restart Chrome. Driveup continues from the last piece Drive received instead of starting over.
  • Know what made it. Every file is checked against Drive's copy, so a ✓ means the copies match.
  • Folders keep their shape. Subfolders are recreated in Drive.

Driveup can only see the files it uploads. Nothing else in your Drive.
